Your Agentic Site Reliability Engineer

Atomic SRE is the autonomous diagnostic engine for microservices. Stream CloudWatch logs, query codebase context via GitHub MCP, and dispatch verified alerts directly to Slack.

Install with one command 
curl -sSL https://raw.githubusercontent.com/DsThakurRawat/Atomic-SRE/main/install.sh | bash
Or run pip install atomic-sre in your Python environment
atomic-sre init
atomic-sre run

How It Works

From log group anomaly detection to Slack resolution reports, in four automated steps.

1

Log Anomaly Ingestion

Monitors CloudWatch streams and isolates stack trace errors automatically.

2

Context Discovery

Uses GitHub MCP to query repository status, blaming file edits and revisions.

3

Multi-Agent Diagnosis

SRE orchestrator plans and conducts deep diagnostic inspections of code paths.

4

Slack Notifications

Pushes root cause summaries and proposed fixes directly to the team channel.

Engine Features

How the autonomous agents coordinate to handle production diagnostic processes.

Log Observation

Direct integration with AWS CloudWatch log streams. Automatically ingests exceptions, tracks trace patterns, and identifies affected microservices.

Codebase Inspection

Utilises Model Context Protocol (MCP) clients to run queries against your repository. Ingests source files and blame logs to understand code context.

Root Cause Diagnosis

Generates detailed root cause analyses and proposes exact, safe code modifications for human review and auditing.
